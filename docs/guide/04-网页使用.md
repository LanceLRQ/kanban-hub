# 网页使用

网页只有一个管理员账号，密码就是部署时设置的 `KH_ADMIN_PASSWORD`。登录后 30 天内有效。

顶栏有三个入口：项目、时间线、设置。点 logo 回到首页。

## 首页：待你处理

首页汇总了所有项目里带“待你处理”标记的任务，按待决策、待验证、待操作分组。每天打开网页，先看这里：AI 卡在哪里等你，一眼就能看到。

还没有任何项目时，首页会提示你去接入引导页。

## 项目列表

`/projects` 列出所有项目的卡片：周期、健康度、当前焦点、进度条、最近活动。长时间没有动静的项目会标“停滞 N 天”。卡片上还能看到项目在哪些机器上、最后一次同步的时间和 git 状态（分支、未提交的改动数、领先落后的提交数）。

## 项目页

点开一个项目，有四个标签页。

### 看板

看板按这个顺序排列：进行中的特性、阶段、储备、杂项。已完成的容器折叠成一行摘要，点开可以展开。宽屏时左侧有容器导航，点一下跳到对应容器。

每个任务一行，显示状态、编号、标题、分组、待你处理、备注、关联文档和日期。点任务行会打开侧边栏，可以修改所有字段：状态、待你处理、清单、备注、所属容器、编号、分组、截止日期、关联文档。修改逐项自动保存。

每个容器末尾有一个输入框，输入标题后回车就能新建任务。容器右上角的“编辑”可以改编号、标题、目标版本、目标日期和手动状态。

有两件事网页上做不了，要用 `kh`：新建容器（`kh container add`），新建项目（`kh register`）。

### 时间线

这个项目的全部事件，按时间倒序排列。

### 文档

左边是文件树，右边显示文件内容。文件树上方可以切换机器，默认显示最近同步的那台机器的快照，旁边标着同步时间。另有“最近更新”列表，列出最近改过的文件。

各类文件的显示方式：

| 文件 | 显示方式 |
|---|---|
| Markdown | 渲染显示，支持 GFM 表格、代码高亮、mermaid 图，标题带锚点 |
| 代码和其他文本 | 代码块加语法高亮。扩展名不认识但内容是文本、且不超过 1MB 的，也按代码显示 |
| 图片 | 直接内嵌显示 |
| HTML、SVG、PDF | 提示在新标签页打开 |
| 其他文件 | 显示文件信息和“打开原文件”链接 |

Markdown 里的相对链接会变成站内跳转。链接指向的文件不在快照里时，保留原文字并提示“文件不在快照中”。

HTML demo 在新标签页里以沙箱方式打开，页面里的脚本可以运行，它引用的 css、js、图片也能用相对路径正常加载。打开的链接 12 小时内有效，过期后刷新文档页即可。

还没有机器同步过这个项目时，文档页会提示你在仓库里执行 `kh sync`。

### 设置

项目页的“设置”标签列出了项目在各台机器上的位置：路径、同步范围、单文件上限、git 状态、最后同步时间，以及因为超过大小上限而没有同步的文件。

这里还能把看板导出成 YAML 或 Markdown 文件，格式说明见《导入导出》。

项目的名称、简介、周期、健康度和焦点，在项目页顶部的“编辑”里修改，四个标签页都能看到这个按钮。

## 跨项目时间线

`/timeline` 是所有项目的事件汇总，按天分组。可以按项目、事件类型、操作者（网页或某台机器）筛选。宽屏时左侧有日期导航。

## 设置

`/settings` 分几块：

- 外观：主题（褪色印刷、纸本拼贴）、页面宽度、等宽字体、中文字体。这些偏好存在浏览器本地，换一台设备要重新选。
- 加密备份：创建备份，查看和下载已有备份。详见《备份与恢复》。
- 服务信息：版本、数据目录、服务地址、停滞阈值、待提交的改动数。
- 已接入的机器：改名、吊销。
- 接入：跳转到接入引导页 `/setup`。

## 实时刷新

网页和服务端保持一条实时连接。AI 上报进度后，看板和首页会自动更新，不需要手动刷新。断线后会自动重连，重连时重新拉取一次数据。标签页切到后台超过 5 秒会断开连接，切回来时重新连接并刷新。
