# 备份与恢复

数据目录本身是一个 git 仓库，每次修改都有提交记录，误改了可以从历史里找回。但磁盘坏了、机器没了，git 历史也跟着没了，所以还需要备份。

目前只支持手动备份。

## 创建备份

两种方式任选：

- 网页：`/settings` 的“加密备份”，输入密码，选择是否包含历史，点“创建加密备份”。创建完成后可以在列表里下载。
- 命令行：`kh backup`，交互输入两遍密码，完成后备份会下载到当前目录。加 `--no-history` 不包含 git 历史。

备份文件保存在服务端的 `backups/` 目录，文件名形如 `kanban-hub-20260930-143000.zip`，时间按服务端时区。

几点说明：

- 备份是 ZIP 文件，用 AES-256 加密（WinZip AE-2 格式），7-Zip 等常见工具都能用密码打开。密码留空就不加密。
- 密码不会被保存，也不会写进日志。忘了密码就无法解开备份，请另外记好。
- 备份包含全部数据，包括用户和机器的凭据文件。所以强烈建议设置密码。
- “含历史”会把数据目录的 git 历史一起打包，文件更大，但恢复后能看到完整的修改记录。
- 备份进行时，其他写入会稍等片刻，保证备份内容一致。同一时间只能有一个备份任务。

备份目录里的文件不会自动清理，也不会自动传到别处。建议定期把 `backups/` 里的文件复制到另一台机器或云盘上。

## 恢复

恢复只能写入空的数据目录，不会覆盖现有数据。

### 用一键脚本恢复

把备份文件放进安装目录的 `backups/`，然后：

```bash
bash kanban-hub.sh restore kanban-hub-20260930-143000.zip
```

脚本会停止容器，把现有的 `data/` 改名为 `data.bak-<时间>` 留存，新建一个空的 `data/`，再从备份恢复。过程中会显示备份的摘要并请你确认，备份有密码时会提示输入。恢复完成后询问是否立即启动。

确认数据无误后，可以手动删掉 `data.bak-<时间>`。恢复失败时，原数据完整保留在 `data.bak-<时间>` 里：删除新建的空 `data/`，把 `data.bak-<时间>` 改回 `data` 即可回退。

### 用 Docker Compose 手动恢复

```bash
cd deploy
docker compose down
mv data data.old && mkdir data            # 数据目录必须是空的
docker compose run --rm kanban-hub restore /backups/kanban-hub-20260930-143000.zip
docker compose up -d
```

`restore` 会先打印备份的摘要（创建时间、是否含历史、备份时的服务端版本），确认后才开始。

密码按这个顺序获取：`--password` 参数，环境变量 `KH_RESTORE_PASSWORD`，终端交互输入。交互输入时直接回车表示备份没加密。`--password` 会留在 shell 历史里，一般用交互输入就好。

在脚本里无人值守地恢复，要加 `--yes` 跳过确认，并用环境变量传密码：

```bash
KH_RESTORE_PASSWORD='你的密码' docker compose run --rm -e KH_RESTORE_PASSWORD kanban-hub restore /backups/<文件> --yes
```

### 不用 Docker 时

`pnpm -F @kanban-hub/web build` 会同时生成 `apps/web/dist/restore.mjs`，参数同上，另外用 `--data-dir` 指定数据目录（不指定时取环境变量 `KH_DATA_DIR`）：

```bash
node apps/web/dist/restore.mjs /path/to/kanban-hub-20260930-143000.zip --data-dir /opt/kanban-hub/data
```

执行前先停止服务。

## 恢复之后

- 管理员密码仍然以环境变量 `KH_ADMIN_PASSWORD` 为准。和备份里的密码哈希不一致时，服务启动时会更新哈希，所有网页会话失效，重新登录即可。
- 机器令牌随备份一起恢复。已接入的机器不需要重新配对，前提是它们连的还是同一个地址。
- 如果恢复到新服务器、地址变了，每台机器要用新地址重新配对：`kh login --server <新地址> --code <配对码>`。重新配对会登记成一台新机器，之后在各仓库里执行一次 `kh register` 补登记位置，再到网页上吊销旧的机器。
