## 从哪里读起

第一次部署：读《部署》和《接入机器与仓库》。读完就能用了，日常进度由 AI 上报，你只需要看网页。

日常使用：读《看板的概念》和《网页使用》，了解看板上各个标记的含义。

多台机器之间共享私有文档：读《文档同步与冲突》。

想亲手操作看板，或者想知道 AI 执行的命令是什么意思：查《kh 命令参考》。

设计上的完整细节（数据模型、API、存储格式）见[设计规格](../superpowers/specs/2026-09-23-kanban-hub-design.md)。
